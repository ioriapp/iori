# ダイアログとポップアップ

モーダルを開くとフォーカスを中へ移し、Tabで操作を巡回する。閉じると開いた操作へ戻る。メニューや候補一覧は外側のクリックやEscで閉じる。補完の操作中は入力欄のフォーカスを保ち、IME変換中のEscは文字変換に使う。

削除・停止・更新などの確認では「キャンセル」に初期フォーカスを置く。背景のクリック、Esc、×、「キャンセル」で実行を確定しない。実行後に表示だけを閉じる操作は「閉じる」とし、処理は続けて進行・結果へ戻れるようにする。

PCでは操作を下端右に並べ、Mobileでは縦に並べ、主な操作を先頭に置く。Mobileの主ボタンの当たり判定は44pxとする。全画面の設定や作成画面は作業面として扱う。

単純な確認の高さは内容に合わせる。導入・更新・アンインストールなど段階のある長い流れでは、状態切替で操作位置が動かない高さにする。画面に収まらない場合は見出しと操作を残し、本文をスクロールできるようにする。

## 未保存の変更

未保存の変更がある画面を閉じたり別の対象へ移ったりするときは、「変更を保存しますか？」と「キャンセル」「保存しない」「保存」を表示する。

- 「キャンセル」、Esc、背景のクリック、×で元の編集へ戻り、入力を保持する。
- 「保存しない」で、その離脱で失われる未保存の変更を破棄して先へ進む。
- 「保存」で、その離脱で失われる未保存の変更を保存してから先へ進む。複数の設定に変更があればそれぞれの保存単位で保存する。失敗があれば移動せず、保存できなかった入力と理由を元の画面に残す。

検索や絞り込みは保存対象に含めない。編集した値を保存済みの値に戻した場合は未変更として扱う。
