# Clientの起動と保存データ

Clientの起動失敗の案内と、以前のバージョンのデータを消して始め直す操作を変更する時に読む。

- 公開前は、以前のバージョンのデータを移行せず、起動時に古い形式であることを示す。
- 「消して始め直す」で登録したHostと下書きが消えること、会話はHostに残ることを同じ画面で短く伝える。削除前に一度確認し、取り消した場合は保存情報を保持する。
- 確認後はこのClientの古い保存領域だけを削除し、初期状態で起動する。Hostの保存領域や他の保存領域には触れない。
- 削除できなかった場合は起動画面に留まり、再試行できる。
- 保存機能や鍵を利用できない場合は保存情報を削除せず、原因の確認と再試行を案内する。古いデータの初期化と混同しない。
