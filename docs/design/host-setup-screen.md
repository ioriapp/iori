# iori Hostを用意する画面

読むのは、DesktopのClientでiori Hostを導入・登録する画面の並び、各欄の名前と説明を変える時である。
導入・更新・撤去の手順と条件は[Hostの導入と更新](host-install-update.md)、接続状態は[接続](connection.md)、設定項目は[設定](settings.md)、招待による登録は[製品仕様](../product.md#初回利用とデバイス追加)が持つ。

## 置き場所と流れ

- Hostが無い時の最初の画面と、設定のHostの区画の「iori Hostを追加する」は、同じ入口の2択を表示する。「iori Hostをセットアップする」から同じ題の一つのモーダルで導入から登録までを終える。「招待で接続する」は招待の画面を開き、「戻る」で2択へ戻れる。設定画面の中に導入の手順を並べない。
- 画面の操作段階は一つで、最後に押すのは「インストールする」（既にiori Hostがある時は「このiori Hostに登録する」）だけである。SSHの接続先を選ぶと、その場で接続と接続先の確認を始める。別の「接続する」ボタンは置かない。
- SSHが求める確認（初めての接続先のhost鍵、passphrase等）は、同じ画面の接続先の下に表示して答えさせる。自動承認しない。
- 「インストールする」の後の取得・導入・接続確認の進捗と、失敗した時の結果は同じモーダルに表示する。進捗は段の一覧（済んだ段に印、今の段に回る印）と、行数を決めたログを、高さを決めた同じ枠の中で「進行状況」「ログ」のタブで見せる（[UIの定義](ui.md)の「ダイアログの高さ」）。進行中と結果の時は、このデバイスの名前と導入先を1行の要約に畳む。
- 導入と登録が終わったらモーダルを閉じ、右下の知らせ（[UIの定義](ui.md)の「時間のかかる操作の流れ」）に「〈接続先〉にiori Hostをインストールし、このデバイスを登録しました。」（既にあるHostの時は「〈接続先〉のiori Hostにこのデバイスを登録しました。」）と出し、登録したiori Hostを選んだ状態にする。ログアウトするとHostが止まるなど注意のある完了は、モーダルを閉じずに結果の画面で表示し、「閉じる」で閉じる。
- MobileのClientには導入を出さない（招待で登録する）。

## 画面の並び

上から次の順に置く。

1. **このデバイスの名前**: OSのデバイス名を初期値にし、書き換えられる。
2. **導入先**: 「このPC」と「別のマシン（SSH）」を切り替える。WindowsとLinuxでは「このPC」を既定にする。
3. **接続先**（別のマシンの時）: 絞り込みの入力と、`~/.ssh/config`の候補の一覧を置く。一覧は高さを抑えて中をスクロールさせ、一覧のすぐ下（一覧の外）に「手動で指定する…」を置く。手入力の欄の下には形の説明（「host、user@host、ssh://user@host:portのいずれかの形式で入力してください。」）を置き、「この接続先を使う」で確かめを始め、「一覧から選ぶ」で一覧へ戻る。選んだ候補と手入力した接続先は一行に畳み、「変更」で一覧へ戻る。接続できたら、OS・user・ホームを一行で表示する。接続先を変えたら、前の接続先で得た値を捨てて取り直す。
4. **ほかのデバイスからの接続**（Windowsの「このPC」の時）: 「ほかのデバイスからの接続を許可する」を既定で選んでおき、そのすぐ下に、導入中に「ユーザー アカウント制御」の確認画面が1回表示されることを一行で表示する。選択を解除した時は同じ行に、このPCからだけ使えることを表示する。接続先がWindowsの時（管理者の時だけ導入できる）は選択を置かず、導入の途中でWindowsファイアウォールに許可を加えることだけを一行で表示する。既にiori Hostがある時は導入しないため、この欄と案内を出さない。
5. 下端に「キャンセル」と「インストールする」。「インストールする」を押せない時、ユーザーが入力・選択すれば押せるようになる時だけ、その操作（「接続先を選んでください」など）を下端の左に表示する。接続中・確認中とSSHの確認の間は表示しない。進み具合の段の一覧を出した後は、「インストールする」を文字のまま押せない表示にする。「キャンセル」はどちらの導入先でもモーダルを閉じる。導入の途中で押した時は「キャンセル中」と表示し、SSHが実際に終了したら「インストールをキャンセルしました。」と表示して接続先の確認の結果へ戻る。

SSHの確認と失敗は接続先の下へ表示する。失敗は、接続を拒まれた・名前が引けない・応答が無い・host鍵が変わった・認証に失敗した、の別に、起きたことと次にすることを表示し、元の文は畳んで添える。host鍵の確認は、接続先の名前とフィンガープリントを表示して一致を確かめるよう日本語で表示し、元の文は小さく添えて、「接続しない」「接続する」で答える。host鍵が変わった時は自動で承認せず、known_hostsを直すよう表示する。passphrase・パスワードには「〈ユーザー〉@〈接続先〉のパスワード」の伏せ字の入力と「接続しない」「送信」で答える。確認内の「接続しない」は接続を取り消し、選び直せる状態にする。FIDO鍵のタッチなど応答の要らない通知は、回る印と「セキュリティキーにタッチしてください。」を表示し、その補助が終了したら非表示にする。接続が終わった時も確認を非表示にする。Linux x64・Windows x64以外なら、対応していないOSまたはCPUと、対応しているもの（Linux x64とWindows x64）を表示する。

## 既にiori Hostがある時

このPCまたは接続先に既にiori Hostがある時は、導入の欄の代わりに、iori Hostの名前・バージョンを表示し、「〈接続先〉には既にiori Host 〈バージョン〉がインストールされています。このデバイスをこのiori Hostに登録します。」と表示して「このiori Hostに登録する」を置く。登録の方法は[導入したデバイスの登録](host-install-update.md#導入したデバイスの登録)に従う。iori Hostのバージョンが古い時は「登録後、設定の「iori Hostを更新」から最新バージョンに更新してください。」を添える。

## 文言

画面の文は、翻訳できる形で書く。一つの概念に一つの語を使い、同じ語を別の意味に使わない。バージョンの表記は「バージョン」と書く。
