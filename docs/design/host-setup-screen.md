# iori Hostを用意する画面

読むのは、DesktopのClientでiori Hostを導入・登録する画面の並び、各欄の名前と説明を変える時である。
導入・更新・撤去の手順と条件は[Hostの導入と更新](host-install-update.md)、接続状態は[接続](connection.md)、設定項目は[設定](settings.md)、招待による登録は[製品仕様](../product.md#初回利用と端末追加)が持つ。

## 置き場所と流れ

- Hostが無い時の最初の画面と、設定のHostの区画の「iori Hostを追加する」は、同じ入口の2択を示す。「iori Hostを用意する」から同じ題の一つのモーダルで導入から登録までを終える。「招待で接続する」は招待の画面を開き、「戻る」で2択へ戻れる。設定画面の中に導入の手順を並べない。
- 画面の操作段階は一つで、最後に押すのは「インストールする」（既にiori Hostがある時は「このiori Hostに登録する」）だけである。SSHの接続先を選ぶと、その場で接続と接続先の確認を始める。別の「接続する」ボタンは置かない。
- SSHが求める確認（初めての接続先のhost鍵、passphrase等）は、同じ画面の接続先の下に示して答えさせる。自動承認しない。
- 「インストールする」の後の取得・導入・接続確認の進捗と、失敗した時の結果は同じモーダルに示す。導入と登録が終わったらモーダルを閉じ、「「〈名前〉」を登録しました」とはっきり示し、登録したiori Hostを選んだ状態にする。
- MobileのClientには導入を出さない（招待で登録する）。

## 画面の並び

上から次の順に置く。

1. **この端末の名前**: OSの端末名を初期値にし、書き換えられる。
2. **導入先**: 「このPC」と「別のマシン（SSH）」を切り替える。WindowsとLinuxでは「このPC」を既定にする。Windowsのiori Hostは「このPC」だけで導入する（[入口](host-install-update.md#入口)）。
3. **接続先**（別のマシンの時）: 絞り込みの入力と、`~/.ssh/config`の候補の一覧を置く。一覧は高さを抑えて中をスクロールさせ、最後に「手動で指定する…」を置く。選んだ候補は一行に畳み、「変更」で一覧へ戻る。手入力の途中や手入力した接続先からも「変更」で一覧へ戻れる。接続できたら、OS・user・ホームを一行で示す。接続先を変えたら、前の接続先で得た値を捨てて取り直す。
4. **ほかの端末からの接続**（Windowsの「このPC」の時）: 「ほかの端末からの接続を許可する」を既定で選んでおく。選んでいる時は、下端の「インストールする」の上に、導入の途中でWindowsの管理者の確認が出ることとその理由を一行で示す。既にiori Hostがある時は導入しないため、この欄と案内を出さない。
5. 下端に「やめる」と「インストールする」。「やめる」はどちらの導入先でもモーダルを閉じる。SSHが動いている時は「SSHの終了を待っています…」と示し、実際に終了してから閉じる。

SSHの確認は元の文を接続先の下へ示す。host鍵のyes/noには「接続する」「やめる」、passphrase・パスワードには伏せ字の入力と「送信」「やめる」で答える。確認内の「やめる」は接続を取り消し、選び直せる状態にする。FIDO鍵のタッチなど応答の要らない通知は文だけを示し、その補助が終了したら消す。接続が終わった時も確認を消す。Linux x64以外なら、対応していないOSまたはCPUを文に入れて示す。

## 既にiori Hostがある時

このPCまたは接続先に既にiori Hostがある時は、導入の欄の代わりに、iori Hostの名前・バージョンを示し、「入れ直さずに、この端末をこのiori Hostに登録します」と説明して「このiori Hostに登録する」を置く。登録の方法は[導入した端末の登録](host-install-update.md#導入した端末の登録)に従う。iori Hostのバージョンが古い時は、登録の後に「iori Hostを更新」から新しいバージョンにできることを添える。

## 文言

画面の文は、翻訳できる形で書く。一つの概念に一つの語を使い、同じ語を別の意味に使わない。バージョンの表記は「バージョン」と書く。
