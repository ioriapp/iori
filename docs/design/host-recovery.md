# Hostとの接続が切れた時の表示

再接続の継続と状態の用語は[接続](connection.md)に従う。

会話、Files、Git、Terminalは最後に表示した内容と入力を保ち、接続が戻ったら同じ作業の現在の状態へ追いつく。接続が戻るまで作用を自動で送り直さず、会話やTerminalを別のセッション・プロセスとして作り直さない。

自動再接続中は、切断の直後には再接続の表示を出さない。しばらく戻らない時だけ、帯を使わず小さい「再接続中」を表示する。さらに長く戻らない時は「○分前の内容を表示しています」を添え、経過は再試行ごとにリセットしない。「最後の応答から X 秒」「受信中」「更新中」とは表示しない。

Hostが再起動していた時、デバイスの登録が取り消された時は、理由と必要な操作を表示する。

送信、判断への回答、Terminalの入力の結果は、CLIの応答や履歴など後から届いた結果で確定する。結果が分からない間も警告や注記を出さず、後続の送信を妨げない。届かなかったと確定した場合だけ、その発言の横に再送を出す。

接続が戻った時は、切断前の表示・入力・読み位置を残したまま、現在の状態へ追いつく。切断していた時間の長さ、Hostの再起動、Clientの再起動によって、ユーザーがすることは変わらない。
